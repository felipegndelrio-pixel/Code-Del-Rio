# NexoProcess · carrossel "O fio" (v1.0)

Um painel contínuo de 7560×1350, cortado em 7 slides de 1080×1350. Um fio de luz atravessa todos: começa em nó, contorna as telas reais do app e termina no símbolo da marca.

| Arquivo | O que é |
|---|---|
| `slides/slide_01.png` … `slide_07.png` | Os 7 slides (Instagram e LinkedIn) |
| `NexoProcess_Fio_painel_7560x1350.png` | O painel inteiro |
| `NexoProcess_Fio_carrossel.pdf` | PDF de 7 páginas (documento do LinkedIn) |
| `gera_fio.cjs`, `monta_pdf.py` | Código de produção |

Reproduzir: `node gera_fio.cjs && python3 -I monta_pdf.py`

Telas: capturas reais do app em `marketing/video/assets/`, com a etiqueta "Exemplo fictício · dados ilustrativos". Fonte: IBM Plex Sans. Nada foi publicado.
